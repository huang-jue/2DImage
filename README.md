# 2D 多帧图像标注

基于 **Vue 3 + Vite + Element Plus + Konva** 的 2D 多帧图像标注工具。

在画布上加载多帧图片，使用矩形 / 点 / 折线 / 多边形工具绘制标注，标注以“跨帧对象（track）”的方式管理：
新建对象可选择延伸到末帧，或只创建一个关键帧，之后插入关键帧并一键插值补全。

## 功能

### 标注

- **多种工具**：矩形（拖拽绘制）、点（单击落点）、折线（连续单击，双击 / 回车结束）、多边形（点击首顶点闭合）。
- **选择与编辑**：点选后可拖动；矩形可缩放；折线 / 多边形可拖动顶点、双击插入顶点、右键删除顶点。
- **多选与批量操作**：Shift+点击多选，可组拖动、批量删除 / 复制 / 改标签 / 改颜色 / 隐藏 / 锁定。
- **画布标签**：对象标签直接显示在图形旁，可随时关闭。
- **标签类别**：预置类别 + 自定义类别，独立颜色，数字快捷键 `1–9` 切换。
- **编辑传播模式**：仅当前帧 / 向后传播 / 全部帧，三种模式随时切换。
- **关键帧插值**：支持「仅当前帧」创建关键帧，跳到后续帧插入关键帧并调整位置后，一键补全中间帧。
- **向前 / 向后补标**：把对象几何补到更早的帧，或把末帧几何延伸到末帧。
- **拆分 / 合并**：在任意帧拆分同一对象；把多选对象合并为一个（重叠帧保留第一个对象的几何）。
- **复制 / 粘贴**：Ctrl+C / Ctrl+V 在帧内、帧间或跨数据集复制对象。
- **方向键微调**：选择工具下选中对象时方向键 1px、Shift 10px 微调；未选中时方向键切帧。
- **对象面板**：搜索、仅本帧筛选、定位、修改标签 / 颜色、隐藏、锁定、删除、关键帧数量显示。
- **撤销 / 重做**：最多 100 步，覆盖新建、编辑、删除、导入等所有写操作。
- **明暗主题**：一键切换，首次跟随系统偏好并记住选择。

### 多帧浏览

- 缩略图、滑块、上一帧 / 下一帧、上一 / 下一标注帧、上一 / 下一未标注帧、跳帧输入。
- 含标注的帧显示绿色标记点，当前帧缩略图自动滚动到可视区域。
- 相邻帧自动预加载，缩略图懒加载。
- 画完自动跳到下一帧（可选）。
- 滚轮以指针为中心缩放，空格 + 拖拽 / 中键拖拽平移，一键适应窗口。

### 数据

- **双数据源**：构建期打包的静态数据集 + 运行时导入的本地图片目录。
- **自动保存**：标注变更 400ms 防抖写入 localStorage，刷新自动恢复。
- **会话恢复**：刷新后恢复上次的数据集、当前帧、编辑 / 新建模式、标签与主题。
- **导入 / 导出**：内部 JSON 可完整往返，另支持 COCO / YOLO / MOT / CSV。
- **导出校验**：空标签、零面积、越界几何在导出前提示。
- **数据校验**：逐帧解码图片，检查加载失败与尺寸不一致；帧数不足仅提示、不影响使用。

## 使用说明

### 数据集

- 顶部单选按钮切换数据集，标签上会显示帧数；点击校验标签也可切换。
- **导入目录**：选择本地图片文件夹作为新数据集。优先使用 File System Access API，不支持时自动降级为目录选择框。
- 本地数据集通过对象 URL 加载，**刷新页面后失效**，需要重新导入同名目录；标注会保留，重新导入后可继续编辑。
- 本地数据集可通过「移除本地数据集」删除（同时清除其标注）。

### 标注与编辑

- 选择工具后，在画布上单击 / 拖拽绘制；新对象默认从当前帧延伸到末帧。
- 工具栏「编辑」选择传播模式：
  - **仅当前帧**：只改当前帧，适合逐帧修正。
  - **向后传播**：改当前帧及之后所有帧（默认）。
  - **全部帧**：改该对象所有帧。
- **插值补全**：在整条对象的所有相邻关键帧之间线性补全空白帧（矩形 / 点 / 点数一致的折线）。
  推荐流程（以 20 帧视频为例）：
  1. 工具栏「新建」选「仅当前帧」，在第 1 帧画出对象（此时只有 1 个关键帧）。
  2. 跳到第 20 帧（选中状态会保留），点「插入关键帧」，对象会按第 1 帧的几何出现在第 20 帧。
  3. 直接拖动 / 缩放这个对象到目标位置。
  4. 点「插值补全」，第 2–19 帧会按两个关键帧线性生成。
  也可以先用「从当前帧起删除」制造空缺，再对剩余关键帧执行插值。
- **向前补标**：跳到对象起始帧之前的帧，选中对象后点击「向前补标」。
- **向后补标**：对象被「从当前帧起删除」截断后，选中对象点击「向后补标」可把末帧几何延伸到末帧。
- 对象面板中可锁定对象，锁定后画布不可拖动 / 缩放 / 改顶点，删除操作也会被拦截。
- 「新建」只影响新对象：「到末帧」会填满当前帧到末帧；「仅当前帧」只创建一个关键帧，
  后续帧需要在对象面板点击该行的「+」或在工具栏点「插入关键帧」才会出现几何。
- 对象在当前帧没有几何时，对象面板会显示「本帧无」；「显示 / 隐藏」只控制已有几何的显隐，不会生成新的帧。
- 插入关键帧时，如果对象处于隐藏状态会自动恢复显示，插入后可直接在画布上拖动。
- **多选**：在画布上 Shift+点击对象，或在对象面板 Shift+点击行；选中后拖动任一对象会带动其它选中对象，工具栏与对象面板支持批量操作。
- **拆分**：跳到对象中间帧，点「拆分」，当前帧及之后成为新对象。
- **合并**：多选同类对象后点「合并」，重叠帧保留第一个选中对象的几何。
- **复制 / 粘贴**：选中对象后 Ctrl+C，切到目标帧 Ctrl+V；粘贴遵循「新建」填充模式，并自动偏移 8px。

### 画布标签

- 顶部「显示标签」控制画布上的标签文字显隐；标签字号随缩放保持屏幕大小。
- 隐藏对象时标签一并隐藏。

### 自动保存与恢复

- 标注自动保存到浏览器 localStorage（键名 `lq2d:annotations:v1`），页面顶部显示保存时间。
- 刷新页面后自动恢复；存储配额不足时会提示导出 JSON 备份。
- 会话状态（数据集 / 当前帧 / 模式 / 标签 / 主题）保存在 `lq2d:session:v1`。
- 本地数据集未重新导入时，其标注会暂时保留在存储中，重新导入同名目录后继续可用。

## 添加数据

### 静态数据集（打包进构建产物）

1. 在 `src/assets/datasets/` 下新建目录，例如 `case4/`。
2. 把该数据集的帧图片放进去，文件名按顺序即可（如 `001.jpg`、`002.jpg` …）。
3. 刷新页面会自动发现新数据集，无需修改代码。

建议每份数据集不少于 20 帧（`src/composables/useDatasets.js` 中的 `MIN_FRAMES`）。

### 本地目录（运行时导入）

点击顶部「导入目录」，选择包含图片的文件夹即可。同名目录重复导入会复用同一数据集 id，
便于刷新后接续原有标注。

## 标注数据模型

标注状态以“跨帧对象（track）”组织，`src/composables/useAnnotation.js`：

```js
track = {
  id,                          // 对象唯一 id，同一目标在所有帧共享
  type: 'rect' | 'point' | 'line' | 'polygon',
  label,                       // 标签
  color,                       // 颜色
  visible,                     // 是否显示
  locked,                      // 是否锁定
  startFrame,                  // 首次出现的帧
  geometries: {                // 键为帧序号，值为该帧几何（原图像素坐标）
    [frameIndex]:
      { x, y, width, height }        // rect
      | { x, y }                     // point
      | { points: [x, y, x, y, ...] } // line / polygon（多边形闭合）
  },
}
```

所有几何均以**原图像素坐标**存储，与画布缩放无关。导出的 JSON 形如：

```json
{
  "dataset": "case1",
  "name": "示例 1",
  "frameCount": 20,
  "exportedAt": "2026-01-01T00:00:00.000Z",
  "tracks": [
    {
      "id": "t1",
      "type": "rect",
      "label": "car",
      "color": "#409eff",
      "visible": true,
      "locked": false,
      "startFrame": 0,
      "endFrame": 19,
      "frames": {
        "0": { "x": 100, "y": 120, "width": 200, "height": 160 }
      }
    }
  ]
}
```

导入时兼容 `frames` 字段与内部 `geometries` 字段；id 冲突会自动重新编号。

## 导出格式

| 格式 | 文件 | 说明 |
| --- | --- | --- |
| 内部 JSON | `<数据集>-annotations.json` | 可再次导入，保留全部逐帧几何 |
| COCO | `<数据集>-coco.json` | images / annotations / categories；折线输出 segmentation |
| YOLO | `classes.txt` + `labels/<帧名>.txt` | 归一化包围盒 `class cx cy w h`；所有类型转换为包围盒 |
| MOT | `<数据集>-mot.txt` | `frame,id,x,y,w,h,conf,class,visibility`，frame 从 1 开始，无表头 |
| CSV | `<数据集>-annotations.csv` | 表头 + 每帧一行，折线点用空格分隔 |

- 导出不包含图片文件。
- 选择「全部数据集」或产生多个文件时自动打包为 zip。
- 导出前会校验空标签、零面积与越界几何，确认后可继续导出。

## 开发与测试

- 单元测试（Vitest）：`npm run test`
  - 覆盖 `useAnnotation` 的创建 / 三种传播模式 / 插值 / 拆分合并 / 批量操作 / 复制粘贴 / 导入导出 / 快照恢复
  - 覆盖导出格式与几何工具
- 端到端测试（Playwright）：`npm run test:e2e`
  - 首次运行前执行 `npx playwright install chromium`
  - 覆盖：切帧回归、绘制后渲染、关键帧插值、多选组拖动、拆分合并、复制粘贴、未标注帧导航、方向键微调、多边形闭合、弹窗快捷键守卫、导出、会话恢复

- CI：`.github/workflows/ci.yml` 在 push / PR 时依次执行 lint、单测、构建与 E2E。
- 画布渲染按 track id 增量更新，同一帧内拖动 / 改色不会重建全部节点；图片缓存带 LRU 上限。
